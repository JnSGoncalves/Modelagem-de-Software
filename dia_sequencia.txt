---
title: UC-01 Cadastrar Clientes
---
sequenceDiagram
    actor Cliente
    participant Cliente as Cliente

    Cliente->>Cliente: confirmarEmail(codigo)

    alt Código válido
        Cliente->>Cliente: atualizarDados(nome, email, cpf, dataNascimento)
        alt Dados válidos e únicos
            Cliente-->>Cliente: cadastroConfirmado()
        else Email ou CPF já existente
            Cliente-->>Cliente: informarContaExistente()
        end
    else Código inválido
        Cliente-->>Cliente: erroCodigo()
    end


---
title: UC-02 Cadastrar no Programa de Fidelidade
---
sequenceDiagram
    actor Cliente
    participant Cliente as Cliente
    participant PagamentoAPI

    Cliente->>Cliente: solicitarAdesaoFidelidade(dadosCartao)
    Cliente->>PagamentoAPI: validarCartao(dadosCartao)

    alt Cartão válido
        PagamentoAPI-->>Cliente: cartaoValido()
        Cliente->>PagamentoAPI: processarPagamento(valorMensalidade)

        alt Pagamento aprovado
            PagamentoAPI-->>Cliente: confirmarTransacao()
            Cliente-->>Cliente: adesaoConfirmada()
        else Sem limite
            PagamentoAPI-->>Cliente: transacaoNaoAprovada()
            Cliente-->>Cliente: informarLimiteInsuficiente()
        end
    else Cartão inválido
        PagamentoAPI-->>Cliente: erroCartaoInvalido()
        Cliente-->>Cliente: informarErroDados()
    end


---
title: UC-03 Reservar Ingresso
---
sequenceDiagram
    actor Cliente
    participant Cinema
    participant Filme
    participant Sessao
    participant Ingresso
    participant Validador_de_Documentos
    participant PagamentoAPI

    Cliente->>Cinema: listarSalas()
    Cliente->>Sessao: verificarDisponibilidadeAssento(numeroAssento)

    alt Cliente fidelidade
        Sessao-->>Cliente: possuiBeneficioFidelidade(dataAtual)
    else Cliente comum
        Sessao-->>Cliente: verificarDisponibilidadeAssento(numeroAssento)
    end

    Cliente->>Ingresso: reservar()

    alt Meia-entrada
        Cliente->>Validador_de_Documentos: validarDocumentos(documentos)

        alt Documento aprovado
            Validador_de_Documentos-->>Ingresso: aprovarDocumento()
            Ingresso->>Ingresso: marcarPendenteValidacao()
        else Documento rejeitado
            Validador_de_Documentos-->>Ingresso: rejeitarDocumento()
            Ingresso->>Ingresso: cancelar()
            Sessao->>Sessao: liberarAssentos(assentos)
        end
    end

    Cliente->>Cliente: informarPagamento(dadosCartao)
    Cliente->>PagamentoAPI: validarCartao(dadosCartao)

    alt Cartão válido
        PagamentoAPI-->>Cliente: cartaoValido()
        Cliente->>PagamentoAPI: processarPagamento(valor)

        alt Pagamento aprovado
            PagamentoAPI-->>Cliente: confirmarTransacao()
            Ingresso->>Ingresso: confirmarPagamento()
        else Pagamento recusado
            PagamentoAPI-->>Cliente: transacaoNaoAprovada()
        end
    else Dados inválidos
        PagamentoAPI-->>Cliente: erroCartaoInvalido()
    end

---
title: UC-05 Visualizar Ingressos Reservados
---
sequenceDiagram
    actor Cliente
    participant Ingresso
    participant PagamentoAPI
    participant Cliente as Cliente

    Cliente->>Cliente: consultarIngressos()
    Ingresso-->>Cliente: listarIngressos()

    opt Nova tentativa de pagamento
        Cliente->>Cliente: informarPagamento(dadosCartao)
        Cliente->>PagamentoAPI: validarCartao(dadosCartao)

        alt Cartão válido
            PagamentoAPI-->>Cliente: cartaoValido()
            Cliente->>PagamentoAPI: processarPagamento(valor)

            alt Pagamento aprovado
                PagamentoAPI-->>Cliente: confirmarTransacao()
                Ingresso->>Ingresso: confirmarPagamento()
            else Pagamento não aprovado
                PagamentoAPI-->>Cliente: transacaoNaoAprovada()
            end
        else Dados inválidos
            PagamentoAPI-->>Cliente: erroCartaoInvalido()
        end
    end

    opt Exportar ingresso
        Cliente->>Cliente: solicitarExportacaoIngresso(ingresso)
        Ingresso->>Ingresso: gerarArquivo()
    end

---
title: UC-08 Gerenciar Filme
---
sequenceDiagram
    actor Administrador
    participant Administrador as Administrador
    participant Filme

    Administrador->>Administrador: solicitarCadastroFilme(filme)

    alt Cadastrar
        Administrador->>Filme: atualizarDados(titulo, duracao, sinopse, classificacao)
        Filme-->>Administrador: operacaoRealizada()
    else Editar
        Administrador->>Administrador: solicitarEdicaoFilme(filme)
        Administrador->>Filme: atualizarDados(titulo, duracao, sinopse, classificacao)
        Filme-->>Administrador: operacaoRealizada()
    else Remover
        Administrador->>Administrador: solicitarRemocaoFilme(filme)
        Administrador->>Filme: remover()
        Filme-->>Administrador: operacaoRealizada()
    end

title: UC-11 Emitir Relatório Consolidado
---

    participant Administrador as Administrador

    participant Filme

    Administrador->>Administrador: solicitarRelatorioConsolidado(periodo)

    end
